# City atlas data

`cities.tsv` is derived from the [GeoNames](https://www.geonames.org/) `cities15000`, `countryInfo`, `admin1CodesASCII` and `timeZones` dumps. GeoNames licenses them under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0).

The data was converted and abridged by `tools/atlas/build_atlas.py`. Do not edit the file by hand; regenerate it instead. [tools/atlas/README.md](../../tools/atlas/README.md) documents the selection rules and the file format.
